# LegalLens AI

An AI-powered legal document analysis and simplification application that helps users understand complex legal documents using Large Language Models (LLMs).

## 🚀 Features

-  Upload and analyze legal PDF documents
-  Generate a document health/risk score
-  Identify potential risks
-  Analyze important clauses
-  Highlight fine print
-  Identify missing clauses
-  Interactive AI chat with the uploaded document
-  Explain complex legal clauses in simple language

##  Tech Stack

- Python
- Streamlit
- Groq API
- Large Language Models (LLMs)
- PyPDF
- python-dotenv
